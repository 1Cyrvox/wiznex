## 中文版 vs 英文原版

同一渲染内核，同一极速性能。区别只在本土化。

| | ManimGX（英文原版） | Wiznex（中文发行版） |
|:---:|:---:|:---:|
| 文档 | 英文 | **全套中文** |
| 界面 / CLI | 英文 | **汉化** |
| 错误信息 | 英文 | **中文** |
| 示例库 | 英文 | **326 部中文动画** |
| 上手门槛 | 需英语 | **开箱即用** |
| 适合人群 | 全球用户 | **中国创作者** |

## 为什么选择 Wiznex

Wiznex 是 ManimGX 的中文本土化发行版，对标 Manim CE，为中国创作者降低数理可视化的使用门槛。

**Wiznex 独有价值：**

| 能力 | 说明 |
|:---|:---|
| 🇨🇳 全套中文文档 | 用户指南、API 参考、教程全中文，开箱即用 |
| 🇨🇳 界面与 CLI 汉化 | 命令行提示、错误信息、交互界面全中文 |
| 🇨🇳 326 部中文示例 | 示例库汉化，中文数学场景直接可用 |
| 🤝 兼容 Manim CE API | 熟悉 Manim CE 的用户无缝迁移 |

**继承自 ManimGX 引擎：**

| 能力 | 说明 |
|:---|:---|
| ⚡ 极速渲染 | Rust + wgpu，比 ManimCE 快 90 倍 |
| 🌐 浏览器运行 | `npm install manimgx`，Pyodide + WebGPU |
| 🤖 智能体反馈 | `manimgx inspect` 故事板和布局检查 |
| ✍️ 文本与数学 | LaTeX 或 Typst，无需安装 LaTeX |
| 🎙️ 语音同步 | `self.say()` 动画与口述匹配 |

## 巨人肩上

[Grant Sanderson](https://www.3blue1brown.com) 创建了 [Manim](https://github.com/3b1b/manim)。ManimGX 以 [Manim CE](https://www.manim.community) API 为目标，Rust + [wgpu](https://wgpu.rs) 渲染。3D 光照改编自 Google [Filament](https://github.com/google/filament)，[Typst](https://typst.app) 排版数学。[Pyodide](https://pyodide.org) 浏览器运行 Python，[x264](https://www.videolan.org/developers/x264.html) 编码 H.264。
