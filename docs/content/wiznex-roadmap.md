# Wiznex 开发路线图

> Wiznex · ManimGX 中文本土化发行版 · 爱派未来科技出品

## 当前已具备

| 能力 | 状态 | 说明 |
|------|------|------|
| 底层渲染内核 | ✅ 已就绪 | ManimGX Rust + wgpu 引擎，不改内核 |
| 中文文档 | ✅ 已就绪 | 全套 API 文档、用户指南中文化 |
| 汉化界面 | ✅ 已就绪 | CLI、错误信息、提示中文 |
| pip 安装 | ✅ 已就绪 | `pip install manimgx`，Python 3.13+ |
| 浏览器运行 | ✅ 已就绪 | `npm install manimgx`，WebGPU + Pyodide |
| 中文示例库 | ✅ 已就绪 | 326 部 mp4 + 481 部 webp 动画 |
| Intel UHD 兼容 | ✅ 已修复 | #004 半透明曲面 + #003 evictable |

## 待开发

### Phase 1 · 在线代码沙盒（play.wlazn.cn）

**目标**：浏览器直接编写、运行、导出数学动画，无需本地配置 Python 环境。

- [ ] 沙盒前端：代码编辑器 + 实时预览窗口
- [ ] 后端：Pyodide Web Worker 运行 Python 场景
- [ ] WebGPU 渲染输出到 Canvas
- [ ] 导出 MP4 / GIF / PNG
- [ ] 预置中文示例模板
- [ ] 分享链接（代码编码到 URL）

**依赖**：ManimGX 浏览器包（npm）已就绪，需封装上层 UI。

### Phase 2 · 可视化编排 IDE

**目标**：上层可视化编排层，不用死记语法，快速搭建数学场景。

- [ ] 拖拽式场景搭建器
- [ ] 几何对象面板（点、线、面、函数、向量）
- [ ] 动画时间轴编排
- [ ] 实时预览 + 代码双向同步
- [ ] 导出 Python 脚本
- [ ] 桌面端应用（Tauri / Electron）

**依赖**：Phase 1 沙盒作为内嵌预览。

### Phase 3 · AI 辅助创作

**目标**：AI 承载数理资料，结合人的创意思想，快速构思数学动画脚本。

- [ ] 自然语言 → 场景脚本（接入大模型）
- [ ] 数学知识库检索
- [ ] 脚本纠错与优化建议
- [ ] 语音讲解自动同步（`self.say()`）

**依赖**：Phase 1 沙盒 + 大模型 API 接入。

### Phase 4 · 社区生态

- [ ] 用户作品画廊
- [ ] 模板市场
- [ ] 协作编辑（多人实时）
- [ ] 教师课件资源包

## 理念

> AI 承载资料，人赋予创见，二者相融，方是良策。
>
> AI 有百科资料，但没有思想不能创新；
> 人有思想创新，但缺少资料途径；
> 相互结合才是良策。

## 架构关系

```
ManimGX ｜底层渲染内核（Rust + wgpu，不改）
    ↓
Wiznex ｜中文生态 + 编排IDE + 在线沙盒（本路线图）
```

Wiznex 不修改 ManimGX 渲染内核，专注构建面向中文用户的完整配套生态，
遵循原项目开源协议。
